## Secondary findings on the natural-language queries

Numbers are recall@5 unless stated; random recall@5 is 5/2,597 = 0.002. Levels: on Q_title, a 0.658,
c 0.792, d 0.794 under E1 (recall@1 0.484, 0.659, 0.666) and a 0.429, c 0.619, d 0.629 under E2; on
Q_desc, a 0.708, c 0.850, d 0.854 under E1 and a 0.413, c 0.642, d 0.653 under E2. A description
is a better query than a title for every representation but a under E2.

1. The loss is on both sides of a text query. With a file as the query the pooled centroid lost
   only where the query's modality was the directory's minority; with a text query it loses on
   text-heavy directories too, by less. Q_title, c - a: E1 text-heavy +0.078 [+0.059, +0.099],
   image-heavy +0.182 [+0.158, +0.206], per bucket +0.105, +0.064, +0.154, +0.250 [+0.203,
   +0.300]; E2 +0.106, +0.263, per bucket +0.143, +0.087, +0.252, +0.292. Q_desc: E1 +0.046
   [+0.027, +0.064], +0.231, per bucket +0.080, +0.028, +0.194, +0.332; E2 +0.091, +0.359, per
   bucket +0.097, +0.087, +0.330, +0.437. In all four runs the loss is smallest in [.2,.5)
   (0.03 to 0.09) and largest in [.8,1] (0.25 to 0.44): a text query reaches a directory
   through its text files, and the pooled vector of an image-heavy directory has few of them
   left. In [0,.2), where almost every file is text, it is 0.08 to 0.14, so part of what a text
   query loses against the centroid is dilution among the directory's own texts, not modality
   (the session 10 reading).
2. Centering the query with the file-side text mean is not a remedy for a query. ac - a on
   Q_title: E1 -0.002 [-0.012, +0.008] over all directories, -0.035 on text-heavy, +0.027 on
   image-heavy; E2 -0.052, -0.119, +0.007. On Q_desc it helps where the query must cross the gap
   and hurts where it need not: E1 +0.035 overall, -0.016 text-heavy, +0.082 image-heavy; E2
   +0.084, -0.067, +0.224. cc - c follows the same sign pattern (Q_title E1 -0.015, E2 -0.092;
   Q_desc E1 +0.010, E2 -0.008). The constant was fitted on file-side text inputs, and the mean
   of a short title is not the mean of a document; nothing was fitted on queries by design.
3. Two vectors lose more against a text query than against a file query. tb2c - c on Q_title:
   E1 -0.065 [-0.078, -0.053] overall, -0.081 text-heavy, -0.051 image-heavy; E2 -0.164, -0.183,
   -0.148. On Q_desc: E1 -0.026, -0.039, -0.014 [-0.028, +0.002]; E2 -0.056, -0.125, +0.008.
   bc2 - c on Q_title: E1 -0.062, -0.105, -0.025; E2 -0.190, -0.249, -0.137; on Q_desc E1
   -0.023, -0.061, +0.013; E2 -0.083, -0.192, +0.019. The uncentered pair tb2 beats its centered
   form on titles (E1 0.742 against 0.727; E2 0.565 against 0.455, and 0.603 against c's 0.588
   on image-heavy directories), the reverse of the file-query picture.
4. c matches the flat walk on text queries too. d - c: Q_title E1 +0.002 [-0.002, +0.007], E2
   +0.010 [+0.004, +0.015]; Q_desc E1 +0.004 [-0.000, +0.008], E2 +0.011 [+0.005, +0.016];
   the largest cell is +0.045 ([0,.2) under E2, Q_title). dc - d is within 0.02 of zero under E1
   and -0.091 under E2 on Q_title (the centering effect of point 2 on the query).
5. The ranking of representations is the same in recall@1 and recall@10 (tables below).
